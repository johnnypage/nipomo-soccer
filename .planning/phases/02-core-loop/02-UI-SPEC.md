## Spacing Scale

Declared values (multiples of 4, using Tailwind `--spacing: 0.25rem` base):

| Token | Value | Tailwind | Usage |
|-------|-------|----------|-------|
| xs | 4px | `gap-1`, `p-1` | Icon-to-label gaps, inline badge padding |
| sm | 8px | `gap-2`, `p-2` | Compact element spacing, track pill padding |
| md | 16px | `gap-4`, `p-4` | Default card body padding, list item gaps |
| lg | 24px | `gap-6`, `p-6` | Section padding inside cards, challenge card body |
| xl | 32px | `gap-8`, `p-8` | Page-level content padding (py-8 on main) |
| 2xl | 48px | `gap-12` | Major section breaks (hero to content) |
| 3xl | 64px | `gap-16` | Not used in this phase |

Exceptions:
- Touch targets on mobile: min 44px height for all tappable elements (Submit Video buttons, tab filters, checkboxes). Use `min-h-[44px]` where Tailwind spacing classes don't reach.

## Typography

All sizes reference the existing Tailwind scale. The site uses a dark theme (`bg-night` with `text-warmwhite`). Matches the Phase 1 challenge hub patterns already in the codebase.

| Role | Size | Weight | Line Height | Font Family | Usage |
|------|------|--------|-------------|-------------|-------|
| Label | 12px (text-xs) | 700 (font-bold) | 1.5 | Inter | Badge text, week indicators, "POINTS" labels, age track names, fitness bonus title, card section headings |
| Body | 14px (text-sm) | 400 (font-normal) | 1.5 | Inter | Challenge descriptions, track descriptions, leaderboard row labels, point counts |
| Heading | 20px (text-xl) | 700 (font-bold) | 1.3 | Inter | Skill challenge title, leaderboard "Top Players", podium point counts |
| Display | 30px (text-3xl) | 700 (font-bold) | 1.1 | Integral CF | Page titles ("Leaderboard"), hero headings. Always uppercase, tracking-wide. |

Integral CF (`font-display` or `font-integral`): always uppercase, `tracking-wide`

## Color

The challenge pages use a dark theme (bg-night #0D0D0D) consistent with the Phase 1 challenge hub.

| Role | Value | Tailwind Class | Usage |
|------|-------|----------------|-------|
| Dominant (60%) | #0D0D0D | `bg-night` | Page background |
| Secondary (30%) | warmwhite/5 to warmwhite/12 | `bg-warmwhite/5`, `border-warmwhite/12` | Cards, containers, borders, dividers |
| Accent (10%) | #C6A045 | `text-gold`, `bg-gold` | See reserved list below |
| Destructive | hsl(0 72% 51%) | `text-destructive` | Error states, file size exceeded messages |
| Success | #2E7D32 | `text-risegreen` | Submission success checkmark, fitness bonus icon, video bonus confirmation |
| Crimson | #8B1D24 | `bg-crimson`, `text-crimson` | Submit Video button background, NSC Player badge, age track label color, 1st place podium rank badge |

**Accent (Gold) reserved for:**
1. Week number indicators ("WEEK 3" pill/label)
2. "Add Kid" action link
3. 1st place podium card border and avatar background
4. Leaderboard hero section label ("SUMMER SKILLS CHALLENGE 2026")
5. Prize section header background
6. Loading spinner border

**Crimson reserved for:**
1. Submit Video button background (primary CTA)
2. NSC Player badge background
3. Age track name labels on challenge track pills
4. Podium rank badges (non-1st place use charcoal, 1st place uses gold)

**Text color hierarchy on dark background:**
- Primary text: `text-warmwhite` (#F4EDE1)
- Secondary text: `text-warmwhite/70`
- Tertiary/muted text: `text-warmwhite/55`
- Disabled text: `text-warmwhite/30`
- Divider borders: `border-warmwhite/10` to `border-warmwhite/12`

## Interaction Contracts

### Submit Video Flow (D-01, D-02, D-03, SUB-01 through SUB-06)

**Default state:**
- Crimson button, white text: "Submit Video" with Lucide `Upload` icon (16px, left of text)
- `min-h-[44px]` for mobile touch target
- Appears inline on both skill and fitness challenge cards

**Upload in progress:**
- Button transforms to show Cloudinary Upload Widget progress
- The Cloudinary Widget itself is a modal overlay (widget's built-in UI)
- While widget is open, the underlying button shows "Uploading..." with a spinner

**Success state (D-02):**
- Button area transforms: green checkmark icon (Lucide `Check`), "+1 point" text in `text-risegreen`, kid's updated total in `text-warmwhite/70`
- Framer Motion: `scale` spring animation on the checkmark (0 -> 1.2 -> 1.0, duration 400ms)
- Framer Motion: `fadeIn` on the "+1 point" text (opacity 0 -> 1, 200ms delay)
- State persists until page refresh or day changes

**Daily cap hit (D-03):**
- Button becomes disabled: `bg-warmwhite/10`, `text-warmwhite/30`, cursor-not-allowed
- Text changes to "Come back tomorrow!"
- Below the button: small text showing kid's current total, e.g. "Mateo has 12 points"
- Tone: encouraging, not restrictive

**Error state (SUB-06):**
- File too large: Cloudinary widget handles this natively (50MB max configured in upload preset)
- Server rejection (daily cap race condition): red inline message "Already submitted today. Come back tomorrow!" in `text-destructive`
- Network error: "Upload failed. Check your connection and try again." in `text-destructive`

### Video Bonus Checkbox (D-05, D-06, PTS-02)

**Default state:**
- Radix Checkbox, unchecked
- Label: "I watched the video (+1 bonus point)"
- Positioned directly below the YouTube iframe embed
- Full-width touch target row (checkbox + label in a flex row, `min-h-[44px]`)

**Checked state:**
- Checkbox fills with `bg-risegreen`
- Label updates: "Video bonus claimed! +1 point"
- Framer Motion: brief checkmark scale pulse (same as submit success)

**Already claimed (D-06):**
- Checkbox checked and disabled, `opacity-50`
- Label: "Video bonus claimed this week"

**No video available (D-07):**
- Entire video embed + checkbox section is not rendered. No placeholder, no messaging. The max points callout for the week simply shows 14 instead of 15.

### Week Navigation (D-13, D-14)

**Current week:**
- Full challenge card at top of page, fully expanded
- Gold "WEEK N" pill badge in card header
- Skill challenge, fitness bonus, and video embed all visible

**Past weeks:**
- Below current week, each in a Radix Collapsible or Accordion item
- Collapsed state: single row with week number, challenge title, and submission status icons:
  - Skill submitted: green filled circle with check (Lucide `CheckCircle2`, `text-risegreen`)
  - Fitness submitted: same green check
  - Video bonus claimed: same green check
  - Not submitted: empty circle outline (`text-warmwhite/30`)
- Expanded state: full challenge card (same as current week) with functional submit buttons for late submission
- Click/tap to expand; click/tap again to collapse

**Future weeks:**
- Not rendered. Hidden completely.

### Leaderboard (D-08 through D-12, LDR-01 through LDR-06)

**Page structure (top to bottom):**
1. Crimson hero banner (LeaderboardHero)
2. Age track filter tabs (Radix Tabs)
3. "Top Players" heading
4. Podium cards (top 3)
5. Player rows (rank 4+)

**Age track tabs (D-10):**
- Radix Tabs: "All" | "Little Kicks" | "Starter" | "Advanced"
- Default: "All"
- Active tab: `bg-charcoal text-warmwhite` (charcoal, matching mockup pattern)
- Inactive tab: `bg-warmwhite/5 text-warmwhite/55 border border-warmwhite/12`
- Hover on inactive: `border-crimson text-crimson`
- Filtering is client-side, all data loaded at once
- On mobile: tabs horizontally scroll if needed (`overflow-x-auto`)

**Podium (D-11):**
- 3-column grid on desktop, single-column stack on mobile (matching mockup responsive behavior)
- 1st place: gold border (2px, `border-gold`), gold avatar background, gold rank badge "1ST"
- 2nd place: charcoal rank badge "2ND", crimson avatar background
- 3rd place: charcoal rank badge "3RD", earth-tone avatar background
- Each card: rank badge (top-left), initials avatar (56px circle), display name, age track (uppercase, text-xs), points (text-xl, font-bold), "POINTS" label, NSC Player badge if applicable

**Player rows (D-12):**
- Each row: rank number (text-sm, font-bold, min-w-[24px]), initials avatar (40px circle), display name + age track, points (right-aligned, text-sm font-bold), NSC Player badge
- Row hover: `border-crimson` transition
- Avatar background colors: cycle through a set of [crimson, gold, risegreen, navy, purple, #5D4037, #1565C0, #E65100] based on kid ID hash for visual variety

**Privacy (PRIV-02, LDR-06):**
- Display names: "First L." format only (e.g., "Mateo L."). Never full last name.

**NSC Player badge (LDR-05):**
- Badge component: crimson background, white text, uppercase, text-xs, font-bold, letter-spacing 0.04em
- Text: "NSC PLAYER"

**Empty leaderboard:**
- Shown when no submissions exist yet (pre-launch or filtered to empty track)
- Trophy icon (Lucide `Trophy`, 48px, `text-gold/40`, centered)
- Heading: "No players yet"
- Body: "Be the first on the leaderboard! Submit a challenge video to start earning points."

**Leaderboard data refresh:**
- TanStack Query with `refetchOnWindowFocus: true`
- Stale time: 30 seconds
- No manual refresh button needed

```
    [3-column TrackPills]

    [VideoBonusCheckbox]

  [Divider]
  [Fitness Bonus section]

    [SubmitButton - fitness]

  [PastWeekRow - Week N-1]
  [PastWeekRow - Week N-2]
  ...
[Footer]
```

- Max width: `max-w-3xl` (48rem / 768px), matching Phase 1
- Page padding: `px-4 py-8`
- Mobile-first: single column, full width cards

### Leaderboard Page (`/challenge/leaderboard`)

```
[Header]
[LeaderboardHero]                      -- crimson banner, full width
  [Label: "SUMMER SKILLS CHALLENGE 2026"]
  [Heading: "LEADERBOARD"]
  [Subtitle: "Week N of 8 -- Challenge Title"]
  [Stats: Total Submissions | Players | This Week]
[Content area - max-w-2xl centered]
  [Radix Tabs - age track filter]
  ["Top Players" heading]
  [Podium - 3 cards]
  [Player rows - rank 4+]
[Footer]
```

- LeaderboardHero: full-width crimson background, no max-width constraint
- Content area: `max-w-2xl` (42rem / 672px) centered, `px-4`
- Stats banner: 3 items in flex row, centered, gap-8

### YouTube Embed

- Responsive 16:9 container using `aspect-video` (Tailwind class)
- Max width: fill parent card (no additional constraint)
- `<iframe>` with `allowfullscreen`, `allow="autoplay; encrypted-media"`
- Rounded corners matching card: `rounded-lg overflow-hidden`

## Responsive Behavior

| Breakpoint | Behavior |
|------------|----------|
| < 640px (mobile) | Podium stacks to single column (cards become horizontal row layout). Track pills stack to 1 column. Tabs scroll horizontally. Stats banner reduces gap. |
| >= 640px (sm+) | Podium shows 3-column grid. Track pills show 3-column grid. Tabs fit inline. |

Mobile is the primary target. Parents will submit videos from their phones.
